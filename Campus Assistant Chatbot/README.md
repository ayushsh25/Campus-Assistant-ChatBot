# 🎓 Campus Assistant Chatbot

A modern and responsive Campus Assistant Chatbot developed using HTML, CSS, and JavaScript. It helps students by answering common queries related to admissions, courses, fees, library, hostel, placement, scholarships, and more.

---

## 🚀 Features

- Modern Glassmorphism UI
- Responsive Design
- Dark & Light Mode
- Voice Recognition
- Text-to-Speech
- Local Storage Support
- Typing Indicator
- Quick Reply Buttons
- 20+ FAQ Responses
- Auto Scroll
- Timestamp
- Clear Chat

---

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome
- Google Fonts
- Web Speech API
